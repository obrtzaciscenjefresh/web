# Project Guidelines

## Architecture

- Next.js 16 App Router (Turbopack), React 19, Tailwind CSS 4, TypeScript 6, Node 24 (`.nvmrc`). Next 16 has breaking changes vs older versions: read the bundled docs in `node_modules/next/dist/docs/` before using unfamiliar APIs (e.g. `next/image` uses `preload`, not `priority`).
- Pages in `src/app/**/page.tsx` are server components. Client components only where needed: `src/components/layout/{MobileMenu,CookieConsent}.tsx` and `src/components/contact/ContactForm.tsx`. Keep it that way for performance.
- Components: `src/components/ui` (primitives), `src/components/layout` (Header, Footer, MobileCtaBar, CookieConsent), `src/components/sections` (page sections), `src/components/legal`.
- Single sources of truth: `src/lib/site.ts` (business data, nav, premises code), `src/data/pricing.ts` (prices), `src/data/faq.ts`, `src/data/reviews.ts`. Never hardcode phone, address or prices in components.
- Routes: `/`, `/kucni-tepisi`, `/uredski-tepisi`, `/kontakt`, `/cjenik`, `/opci-uvjeti-poslovanja`, `/pravila-privatnosti`. `/uvjeti-poslovanja` and `/opci-uvjeti-poslovanja-pranje-tepiha` permanently redirect (see `next.config.ts`). Anchors `/#onama` and `/#usluge` must keep working.

## Prices And Anchor Prices (NN 101/2026)

- Every visible price must be rendered with `PriceTag` (or `anchorLabel`) so the anchor price ("Cijena na 10. 9. 2026.") is shown next to it. Don't write price amounts into free text.
- On any price change, append a new entry to `priceListPublications` in `src/data/pricing.ts` with a full items snapshot, new `publishedAt` and `sequence`; never edit or remove older entries (they must stay online 30+ days).
- CSV/XML files are generated by `src/lib/price-list.ts` and served from `/cjenik/[datoteka]`, `/cjenik.csv`, `/cjenik.xml`. Keep them crawlable (`src/app/robots.ts`).

## Contact Form

- `ContactForm` POSTs JSON to `src/app/api/contact/route.ts` (Resend, `RESEND_API_KEY` in `.env.local`, see `env.template`). Field names and limits must match between form and route; user input is HTML-escaped in the route.

## Analytics And SEO

- The Google tag loads only via `enableAnalytics()` in `CookieConsent.tsx` after consent (localStorage key `fresh-cookie-consent`). Never add tracking scripts to the layout.
- Every page exports `metadata` with `alternates.canonical`; root layout sets the title template. One `h1` per page.
- JSON-LD: business + website in `src/app/layout.tsx`, `Breadcrumbs`, `Faq` and service pages emit their own via `JsonLd`. Add new pages to `src/app/sitemap.ts`.

## Build And Test

- `nvm use` then `npm install`, `npm run dev`, `npm run lint` (ESLint CLI flat config), `npm run build`.
- No test runner; verify with lint, build and `next start`. `next/font/google` needs network on a clean build.

## Conventions

- `@/*` alias for `src`. Tailwind tokens (`primary`, `secondary`, `ink`, `muted`, font) live in `@theme` in `src/app/globals.css`; there is no `tailwind.config.ts`. Use `cn()` from `src/lib/utils.ts`.
- Primary `#2c549d` and secondary `#459cb2` come from the logo; keep them as main colors. Font: Plus Jakarta Sans with `latin-ext`.
- Icons from `react-icons/fa6`. Croatian copy only; keep claims consistent with existing content.
