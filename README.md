# Fresh - pranje tepiha Zagreb

Next.js 16 (App Router, Turbopack), React 19, Tailwind CSS 4, TypeScript. Zahtijeva Node 24 (`.nvmrc`).

## Pokretanje

```bash
nvm use
npm install
cp env.template .env.local   # upiši RESEND_API_KEY
npm run dev
```

## Skripte

- `npm run dev` - razvojni server
- `npm run lint` - ESLint
- `npm run build` - produkcijski build
- `npm run start` - pokretanje builda

Smjernice za projekt (arhitektura, cijene i sidrene cijene, analitika) nalaze se u [AGENTS.md](AGENTS.md).
